# Руководство пользователя языка PLI

**PLI** (Programming Language Interpreter) — учебный императивный язык программирования с динамической типизацией. Программы на PLI выполняются интерпретатором `pli`, который разбирает исходный код и исполняет его без отдельной стадии компиляции.

Формальное описание грамматики: `syntax.ebnf`.

## Установка и запуск

### Сборка интерпретатора

```bash
cd PLI
mkdir -p build && cd build
cmake ..
cmake --build . --target pli
```

Исполняемый файл: `build/bin/pli`.

### Режимы запуска

**Из файла:**

```bash
./build/bin/pli examples/fact.pli
```

**Интерактивный ввод** (без аргументов):

```bash
./build/bin/pli
```

Интерпретатор предложит ввести программу построчно. Пустая строка завершает ввод и запускает выполнение.

### Режимы сборки

| Режим | Команда | Описание |
|-------|---------|----------|
| Release | `cmake ..` | Оптимизация `-O2` (по умолчанию) |
| Debug | `cmake .. -DCMAKE_BUILD_TYPE=Debug` | Отладочные символы `-g` |
| Анализ | `cmake --build . --target analyze` | Статический анализ clang-tidy |

## Первая программа

```pli
var name = "PLI"
var version = 1

print("Hello from ", name, version)
```

Результат:

```
Hello from PLI 1
```

Программа состоит из последовательности **инструкций**, по одной на строку. Точка с запятой в конце строки не требуется.

## Лексические правила

### Ключевые слова

| Ключевое слово | Назначение |
|----------------|------------|
| `var` | объявление переменной |
| `if`, `else` | условный оператор |
| `while` | цикл |
| `print` | вывод на экран |
| `read` | ввод с клавиатуры |
| `and`, `or`, `not` | логические операторы |
| `true`, `false` | логические литералы |

### Идентификаторы

- Начинаются с буквы
- Могут содержать буквы, цифры и символ `_`
- Не могут начинаться с `_` или содержать `__`
- Максимальная длина: **64 символа**

Примеры: `x`, `count`, `my_var`, `grade1`.

### Числовые литералы

```
42
-7
3.14
0.5
```

- Целые и дробные числа
- Допускается унарный минус
- Максимальная длина числа: **30 символов**

### Строковые литералы

```
"Hello"
"Grade: "
```

- Заключаются в двойные кавычки `"`
- Максимальная длина: **64 символа**

### Разделители и операторы

```
( ) { } , = == != < > <= >= + - * / %
```

### Комментарии

В текущей версии языка **комментарии не поддерживаются**.

## Типы данных

PLI использует динамическую типизацию: тип значения определяется во время выполнения.

| Тип | Пример | Описание |
|-----|--------|----------|
| `int` | `42`, `-1` | целое число |
| `float` | `3.14`, `0.5` | число с плавающей точкой |
| `bool` | `true`, `false` | логическое значение |
| `string` | `"text"` | строка |
| `none` | — | отсутствие значения (служебный тип) |

### Правила работы с типами

- **Сложение строк:** `"Hello" + " World"` → `"Hello World"`
- **Арифметика:** операции `+`, `-`, `*`, `/`, `%` работают с числами; если один из операндов — `float`, результат будет `float`
- **Деление** `/` всегда возвращает `float`
- **Сравнение** `==` и `!=`: одинаковые типы сравниваются напрямую; `int` и `float` сравниваются как числа
- **Истинность** в условиях `if` и `while`:
  - `bool` — по значению
  - `int` / `float` — истинно, если не равно нулю
  - `string` — истинно, если непустая

## Выражения и операторы

### Приоритет операторов

От высшего к низшему:

| Приоритет | Операторы | Описание |
|-----------|-----------|----------|
| 1 | `-`, `not` | унарные |
| 2 | `*`, `/`, `%` | умножение, деление, остаток |
| 3 | `+`, `-` | сложение, вычитание |
| 4 | `==`, `!=`, `<`, `>`, `<=`, `>=` | сравнение |
| 5 | `and`, `or` | логические (с укороченным вычислением) |

Скобки `()` изменяют порядок вычисления:

```pli
var result = (2 + 3) * 4
print(result)
```

### Логические операторы

Операторы `and` и `or` поддерживают **укороченное вычисление** (short-circuit):

```pli
var x = 0
if (x != 0 and 10 / x > 1) {
    print("не выполнится")
}
```

## Инструкции языка

### Объявление переменной

```pli
var имя = выражение
```

```pli
var age = 25
var pi = 3.14
var flag = true
var msg = "ready"
```

Повторное объявление переменной с тем же именем — **ошибка**.

### Присваивание

```pli
имя = выражение
```

```pli
var count = 0
count = count + 1
```

Присваивание несуществующей переменной (без предварительного `var`) — **ошибка**, кроме случая `read()` (см. ниже).

### Условный оператор

```pli
if (условие) {
    инструкции
}
```

```pli
if (условие) {
    инструкции
} else {
    инструкции
}
```

```pli
var score = 85

if (score >= 90) {
    print("Отлично")
} else {
    if (score >= 60) {
        print("Зачёт")
    } else {
        print("Незачёт")
    }
}
```

### Цикл `while`

```pli
while (условие) {
    инструкции
}
```

```pli
var i = 1
while (i <= 5) {
    print(i)
    i = i + 1
}
```

### Блоки

Блок — последовательность инструкций в фигурных скобках `{ }`. Используется в `if`, `else` и `while`.

## Ввод и вывод

### `print`

```pli
print(выражение)
print(выражение1, выражение2, ...)
```

- До **24** аргументов
- Аргументы выводятся через пробел
- После последнего аргумента — перевод строки

```pli
print("Sum = ", 10 + 20)
print("Done")
```

### `read`

```pli
read(имя_переменной)
```

Читает одну строку с клавиатуры (до перевода строки) и записывает в переменную.

Тип вводимого значения определяется автоматически:

| Ввод | Тип |
|------|-----|
| `true` | `bool` |
| `false` | `bool` |
| `42` | `int` |
| `3.14` | `float` |
| `hello` | `string` |

Если переменная уже существует — значение обновляется. Если нет — переменная создаётся автоматически.

```pli
var name = ""
print("Enter your name:")
read(name)
print("Hello, ", name)
```

## Примеры программ

В каталоге `examples/` находятся готовые программы:

| Файл | Описание |
|------|----------|
| `fact.pli` | вычисление факториала |
| `if_while.pli` | цикл с проверкой чётности |
| `logic.pli` | логические операторы |
| `gradebook_stats.pli` | статистика оценок с вводом |
| `complex.pli` | комбинированный пример |

### Факториал

```pli
var n = 5
var result = 1
var i = 1

while (i <= n) {
    result = result * i
    i = i + 1
}

print("Factorial of ", n, " is ", result)
```

### Чтение и условие

```pli
var age = 0
print("Enter age:")
read(age)

if (age >= 18) {
    print("Adult")
} else {
    print("Minor")
}
```

## Ограничения языка

В текущей версии **не поддерживаются**:

- функции и процедуры
- массивы и списки
- циклы `for`
- комментарии в коде
- точка с запятой `;` как разделитель инструкций
- ключевое слово `const` (хотя механизм есть во внутренней реализации)
- модули и импорт
- работа с файлами из программы на PLI

Максимальные ограничения:

| Параметр | Значение |
|----------|----------|
| Длина имени переменной | 64 символа |
| Длина строки | 64 символа |
| Аргументов в `print()` | 24 |
| Токенов в программе | 5000 |

## Сообщения об ошибках

Интерпретатор сообщает об ошибках на этапах:

1. **Лексический анализ** — неверный символ, незакрытая строка, слишком длинный идентификатор
2. **Синтаксический анализ** — пропущена скобка, неверная конструкция
3. **Выполнение** — необъявленная переменная, деление на ноль, несовместимые типы

Примеры сообщений:

```
InvalidIdentifierError
MissingClosingParenthesisError
UndefinedVariable
DivisionByZero
UnsupportedOpForType
```

При завершении программы накопленные ошибки выводятся автоматически.
